# 든든 (Deundeun) — 과제 시연용 프로토타입

React + Vite 기반의 식재료 관리 및 레시피 공유 웹서비스입니다.

## 실행 방법

1. Node.js 20.19 이상 또는 22.12 이상을 설치합니다.
2. 이 폴더에서 터미널을 엽니다.
3. 아래 명령을 순서대로 실행합니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 `http://localhost:5173` 주소로 접속합니다.

## 구현된 주요 기능

- 회원가입, 로그인, 로그아웃 및 로그인 상태 유지
- 계정별 냉장고 데이터 분리(현재 브라우저 로컬 저장)
- 식재료 등록, 수정, 삭제, 수량·단위·유통기한 관리
- 유통기한 임박 재료 표시
- 보유 재료 기반 레시피 추천 및 검색
- 레시피 인분 선택, 재료 부족 안내
- 가진 재료만으로 조리 및 실제 사용량 재고 차감
- 조리 이력 및 소비 기록
- 친구 검색, 요청, 수락, 거절, 삭제
- 냉장고 공개 범위 설정 및 탐색
- 커뮤니티 게시글, 좋아요, 댓글, 본인 게시글·댓글 삭제
- PC 및 모바일 반응형 화면

## 데이터 저장 및 시연 범위 안내

이 버전은 별도 서버 계정이나 Supabase 프로젝트 없이 바로 실행할 수 있도록 `localStorage`를 사용하는 과제 시연용 프로토타입입니다. 따라서 계정과 데이터는 **현재 브라우저에만 저장**되며, 다른 컴퓨터·브라우저와 자동으로 동기화되지 않습니다. 데모 계정의 비밀번호도 로컬 시연용 데이터입니다.

실제 공개 서비스로 배포하려면 Supabase Auth 및 PostgreSQL 데이터베이스 연결, 서버 측 권한 정책(RLS), 비밀번호·세션 관리 구성이 추가되어야 합니다. 현재 구현을 실제 서비스 수준의 인증·보안으로 간주하면 안 됩니다.

## 참고

- `node_modules`는 ZIP에 포함하지 않았습니다. `npm install`로 현재 운영체제에 맞는 의존성을 설치합니다.
- 기존 레시피 데이터(`src/recipes.js`)를 유지했습니다.
